# Community Health Files And Org Profile

## Description
None of the org's public repos has CONTRIBUTING, SECURITY or issue templates, and the org has no profile README. Add a `.github` repo providing org-wide defaults so contributors and security reporters know what to do.

## Acceptance Criteria
- [ ] A `.github` repo exists with CONTRIBUTING, SECURITY and CODE_OF_CONDUCT defaults inherited by every repo
- [ ] Issue and PR templates are provided, including a field for MUGEN/Ikemen GO version and a sample file
- [ ] An org profile README links to the showcase site and lists the repos
- [ ] repos.md mentions the new repo

## Notes
Keep it short; contributors mainly report incompatible real-world files, so the template should make attaching a minimal sample easy.
