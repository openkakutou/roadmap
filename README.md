# roadmap

Cross-project planning for the [OpenKakutou](https://github.com/openkakutou) organization: which repos exist or are planned, how they depend on each other, and the backlog of decisions/work that spans more than one repo.

This repo has no code. It exists so planning survives outside any single project's own backlog.

- [`repos.md`](repos.md) — status of every repo in the organization (existing and planned)
- [`.vibe/backlog/`](.vibe/backlog) — org-level backlog items (new repos, cross-repo coordination)
- [`.vibe/decisions/`](.vibe/decisions) — architectural/organizational decisions that span repos

Work that belongs to a single repo (features, bugs, that repo's own architecture decisions) lives in that repo's own `.vibe/`, not here — see [`CLAUDE.md`](CLAUDE.md) for the exact split.
